# ISM Young English

Aplicativo de inglês para estudantes de 10–15 anos, versão 10. São 144 aulas em seis níveis e quinze modalidades de jogos. Os cinco novos jogos trabalham vocabulário, palavras em contexto, gramática, reconstrução de frases e escrita com autoavaliação. Esta distribuição é uma demonstração; os planos não implementam cobrança ou controle de acesso no servidor.

## Verificar e construir

Requer Node.js. Execute `npm run check` e `npm run build`. A saída está em `dist/`; não há dependências externas de build.

## GitHub e Vercel

Repositório: https://github.com/atendimentoinglessobmedida-cell/youngenglish. A publicação de todo o código, aulas e imagens neste repositório público foi autorizada pelo proprietário. A importação na Vercel usa a equipe `equipesonar-1862` e a configuração de `vercel.json`.

As URLs `.html` são preservadas porque o aplicativo utiliza esses caminhos. Configuração: [documentação oficial da Vercel](https://vercel.com/docs/project-configuration/vercel-json).

Não incluir credenciais ou arquivos de alunos. O e-mail do professor ainda aguarda confirmação.
