# ISM Game Lab

Sistema autoral de jogos educacionais para o Young English.

Mecânicas planejadas: Match Sprint, Memory Match, Mystery Reveal, Spelling Rush, Sentence Builder, Grammar Pop, Listen & Choose, Word Hunt, Dialogue Quest e Route Challenge.

Regras: conteúdo ISM original; mobile-first; teclado e toque; sem interação exclusivamente por arrastar; feedback explicativo; retry; integração progressiva com Practice My Mistakes; XP somente por conclusão demonstrada; reduced-motion; preservar chaves atuais de progresso.

Os jogos reutilizam vocabulário e estruturas das aulas de Pre-A1 a C1 e aumentam dificuldade por tamanho do vocabulário, similaridade dos distratores e complexidade das frases.
